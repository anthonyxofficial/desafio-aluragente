# 🤖 Asistente Virtual de Atención al Cliente - Challenge AlurAgente

¡Bienvenido al repositorio del **Asistente Virtual de Atención al Cliente**! Este proyecto fue desarrollado como parte del **Challenge AlurAgente** de Alura Latam.

## 📌 Descripción del Proyecto

El proyecto consiste en un agente interactivo enfocado en la atención al cliente para consultas frecuentes (horarios, ubicaciones, métodos de pago, entregas a domicilio y canales de contacto). El agente lee la documentación del negocio estructurada en un archivo `.csv` y responde las consultas de los usuarios en lenguaje natural a través de una interfaz de chat.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Python
* **Interfaz Web:** Streamlit
* **Procesamiento de Datos:** Pandas
* **Plataforma:** Streamlit Community Cloud

---

## 💬 Ejemplos de Consultas

* `¿Cuáles son sus horarios de atención?`
* `¿Dónde están ubicados?`
* `¿Quiero saber los métodos de pago?`
* `¿Tienen servicio a domicilio?`

---

## 🚀 Instalación y Ejecución Local

1. Clonar el repositorio.
2. Instalar dependencias: `pip install -r requirements.txt`
3. Ejecutar la aplicación: `streamlit run app.py`
